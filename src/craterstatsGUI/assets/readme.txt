
In this directory:

craterstats.exe

    This is the Craterstats executable. Double-click to start the GUI.
    If command line parameters are passed to it, it will operate in command line mode (https://github.com/ggmichael/craterstats)

optionally_create_desktop_command_line_shortcut.bat (Windows only)

    Double-click this bat file to create a desktop shortcut for command line operation of Craterstats if you need it.

LICENSE.TXT

sample/

    Example data files. You can model your own on these if needed.
    OpenCraterTool is recommended for producing .scc files from QGIS (Thomas Heyer)
    It is possible to open filename_CRATER.shp, filename_AREA.shp shapefile sets from ArcPRO directly.

demo/

    Example plot files. Open a few to explore the features of Craterstats-III

_internal/

    Libraries for operation of CraterstatsGUI
